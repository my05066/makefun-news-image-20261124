A Node program that publishes a single front page of world news for Tuesday 24 November 2026. It leads with Jensen Huang’s return to Nvidia and Tuesday’s reversal after Monday’s rally. Illustrated stories cover Kyiv’s claim of a sea-drone strike off Libya, Sanofi’s $41 billion Insmed deal, 14 countries backing the ICJ’s Rohingya ruling, and Shenzhou-24 carrying Tiangong’s first foreign astronaut. A news strip covers the Zaporizhzhia strike, Nepal’s earthquake, and Senegal’s restored AFCON title alongside a markets ticker.

`make_image.py` draws the bundled 1024 × 1024 `entry.png` deterministically with Pillow and local fonts.

## Run it

```sh
node main.ts
```
